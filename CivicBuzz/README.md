# CivicBuzz
AI-powered multilingual civic grievance and participatory budgeting platform
# Finalised Features:
CLIENT PAGE:
1. (under report issue button)Multilingual support (English + 1 regional lang(hindi))
2. 8.(under Track Complains button):Identification of duplicate complaints and ranking them in higher priority, people will be able to view previous complains and theyll be arranged based on priority of urgency(based on the votes / duplicate complains)
3. (under report issue button)text and voice support
4. (under report issue button)Privacy protection of user complaints**(differentiating factor)**
5. (under report issue button)ai identification and analysis of user complaints and redirecting it to responsible authories
6. integrated map support(Map view button): warns users of the routes with possibility of a road break or a persisting issue**(differentiating factor)**
7. review system(under Track Complains button): user can review a resolution and can challenge it, the authgories arent allowed to flag a dispute "closed" its in the hands of the user who has placed the complain**(differentiating factor)**
ADMIN PAGE:
1.Budget advisor : ai recommends the admin what actions to be taken based on priority of issues.
2.upload tenders: allows the admin to upload tenders for the projects(example road fixation) and private companies to take up those tenders and wwork on it.
3.QR code : after and issue is flaged resolved , it generates a printable and scannable qr code that has the full evidence trail of the work done(documents , before after videos, and photos) pushes transparency.
